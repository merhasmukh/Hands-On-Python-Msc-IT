💡 ORM Teaching Note

When you submit this form, Flask receives form inputs via request.form.

Instead of manually constructing an SQL INSERT INTO or UPDATE string, Flask-SQLAlchemy manages the record as a Python object:

# 1. Create or retrieve Python instance
student = Student(name=..., dept_id=...)

# 2. Stage changes into SQLAlchemy session
db.session.add(student)

# 3. Commit the transaction to SQLite
db.session.commit()

This guarantees parameterized security against SQL Injection and automatic type casting!
